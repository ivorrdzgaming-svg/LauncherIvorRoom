# IvorRoom — téléchargements Windows

Ce dépôt public sert uniquement à distribuer les installateurs Windows du launcher IvorRoom. Le code source est conservé dans un dépôt privé séparé et n’est pas inclus ici.

Télécharge le fichier `IvorRoom-Setup.exe` depuis la release la plus récente dans l’onglet **Releases**.

À partir de la version 1.2.0, le launcher consulte les releases de ce dépôt pour proposer les mises à jour. Les versions déjà installées utilisant l’adresse `ivorrdzgaming-svg/LauncherIvorRoom` continuent ainsi à trouver les nouvelles releases.
